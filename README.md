# 12 Week Focus

Готовое статическое приложение для системы «12 недель в году».

## Возможности
- 12-недельные циклы с датой начала, «почему» и видением.
- До 3 главных целей.
- Ключевые действия по неделям и дням.
- Автоматический Weekly Scorecard: выполнено / всего × 100.
- Средний score цикла.
- Индикатор 85%+ как ориентир сильного исполнения.
- Недельный разбор: что сработало, что изменить, победа недели.
- Экспорт/импорт данных JSON.
- Светлая/тёмная тема.
- Адаптивная мобильная версия для iPhone.
- Все данные сохраняются в localStorage браузера; сервер и база данных не нужны.

## GitHub Pages
1. Создай новый репозиторий.
2. Загрузи все файлы из этой папки в корень репозитория.
3. Settings → Pages → Deploy from a branch → `main` / `/ (root)`.
4. Открой выданный GitHub Pages URL в Safari.
5. На iPhone: Поделиться → На экран «Домой».

Это обычный HTML/CSS/JavaScript-проект и не требует Node.js или сборки.
